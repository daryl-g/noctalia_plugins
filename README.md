# noctalia_plugins

A repository for my custom-built Hyprland/Noctalia (Arch Linux) plugins, built using Lua.

## Current plugins

- [`f1_plugins`](./f1_plugins/): Desktop & panel plugins to display F1 team, driver information, results, and latest race results using open source F1 data.

## Planned plugins

- `football_plugins`: Football Manager-inspired, desktop plugins to display advanced football stats from chosen team and player, and a native scouting platform to keep track of scouted players and their data.
